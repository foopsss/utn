# utn
En este repositorio almaceno ejercicios hechos durante el cursado de distintas materias en la carrera de Ingeniería en Sistemas de Información de la UTN FRRe. Acá se pueden encontrar ejercicios de las siguientes materias actualmente:

* Algoritmos y Estructuras de Datos (carpeta «algoritmos»).
* Paradigmas de Programación (carpeta «paradigmas»).

Las carpetas de cada materia incluyen de ser necesario sus propios README con más detalles. De ser posible, para cada materia comparto enlaces a resoluciones de ejercicios de otros compañeros de la carrera.

# Uso de git hooks
Este repositorio usa los [git hooks](https://git-scm.com/book/en/v2/Customizing-Git-Git-Hooks) que se encuentran disponibles en la carpeta "git-hooks", ubicados ahí con la finalidad de poder versionarlos fácilmente. Como esta ubicación no es la estándar, se deberá ejecutar el siguiente comando en caso de querer utilizar los git hooks disponibles al trabajar en el repositorio: `git config core.hooksPath git-hooks/`.
